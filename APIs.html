APRENDA AGORA: MAIS SOBRE APIs

O que é uma API?

Uma API é uma forma de comunicação entre diferentes sistemas. Ela permite que um sistema envie informações para outro e receba uma resposta, sem precisar saber exatamente como o outro sistema funciona internamente.


Para que serve?

A API serve para facilitar a comunicação entre aplicações. Ela pode ser usada para buscar informações, enviar dados, atualizar informações ou realizar alguma ação em outro sistema.


O que é API REST?

API REST é um tipo de API que utiliza os padrões da Web para permitir a comunicação entre sistemas. Ela normalmente utiliza o protocolo HTTP e métodos como GET, POST, PUT, PATCH e DELETE para trabalhar com informações.


O que são endpoints?

Os endpoints são os endereços específicos de uma API usados para acessar determinada informação ou função. Por exemplo, um endpoint pode ser criado para consultar usuários, produtos ou pedidos.


Como o Front-End utiliza uma API?

O Front-End utiliza uma API enviando requisições para buscar ou enviar informações. Por exemplo, ao abrir uma página que mostra uma lista de produtos, o Front-End pode pedir esses dados para uma API e depois apresentar os produtos na tela.

Agora vamos ver alguns métodos

  1. GET

    2. O método GET é usado para buscar ou consultar informações. Exemplo: consultar a lista de produtos de uma loja.

  2. POST

    3. O método POST é usado para enviar informações e criar algo novo. Exemplo: cadastrar um novo usuário em um site.

  3. PUT

    4. O método PUT é usado para atualizar completamente uma informação existente Exemplo: alterar todos os dados de um cadastro de usuário.

  4. PATCH

    5. O método PATCH também serve para atualizar informações, mas normalmente é usado quando queremos alterar apenas uma parte dos dados. Exemplo: alterar somente o telefone de um usuário.

  5. DELETE

    6. O método DELETE é usado para excluir uma informação. Exemplo: apagar um cadastro de usuário ou remover um produto de uma lista.
