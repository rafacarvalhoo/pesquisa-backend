VAMOS ENTENDER: COMO FUNCIONA O BACK-END

  1. Cliente e Servidor

    2. O cliente é o dispositivo que o usuário utiliza, como celular ou computador. Já o servidor é responsável por receber as solicitações do cliente, processar as informações e enviar uma resposta.


  2. Requisição e Resposta

    3. A requisição acontece quando o usuário realiza alguma ação, como fazer login ou enviar um formulário. O servidor recebe essa solicitação, realiza o processamento necessário e envia uma resposta de volta.


  3. HTTP E HTTPS

    4. O HTTP é um protocolo usado para a comunicação entre o cliente e o servidor. Já o HTTPS funciona de forma semelhante, mas possui uma camada de segurança que ajuda a proteger as informações durante a comunicação.


  4. Servidor Web

    5. O servidor Web é responsável por receber as solicitações dos usuários e entregar os conteúdos ou informações solicitadas. Ele ajuda a fazer a comunicação entre o navegador e a aplicação.


  5. Regras de negócio

    6. As regras de negócio são as condições que definem como o sistema deve funcionar. Por exemplo, um site pode determinar que uma compra só pode ser finalizada depois que o pagamento for aprovado.


  6. Validação de dados

    7. A validação de dados verifica se as informações enviadas pelo usuário estão corretas e dentro do que o sistema permite. Isso ajuda a evitar erros e informações inválidas.


  7. Processamento no servidor

    8. Depois de receber uma solicitação, o servidor processa os dados, realiza as ações necessárias e pode consultar ou alterar informações no banco de dados. No final, envia o resultado de volta para o usuário.


  8. O que acontece quando o usuário realiza uma ação?

    9. Quando o usuário realiza uma ação em um site, como clicar em um botão ou enviar um formulário, o Front-End envia uma solicitação para o Back-End. O Back-End recebe essa informação e verifica o que precisa ser feito, podendo consultar ou alterar dados no banco de dados. Depois de realizar o processamento, ele envia uma resposta de volta para o Front-End, que apresenta o resultado para o usuário.
